# Регистрация по статику и паролю

1. В Supabase → Authentication → Providers → Email отключите **Confirm email**. Это обязательно для новых аккаунтов: Supabase Auth внутри использует технический адрес вида `static-12345@army-docymenti.netlify.app`, на него нельзя доставить письмо.
2. Загрузите сайт на Netlify, сохранив действующий `config.js` того же проекта Supabase.
3. Зарегистрируйте тестового персонажа с уникальным числовым статиком и паролем не короче 8 символов.
4. Вход: статик + пароль. Старые аккаунты не удалены: для них в форме входа оставлена раскрывающаяся опция входа по старой почте.

Важно: это переходная реализация на Supabase Auth с техническим email, а не отдельная система аутентификации. Восстановление пароля по email для новых аккаунтов недоступно; понадобится отдельная администраторская процедура сброса. Нельзя считать имя/статик подтверждённой личностью персонажа. Рекомендуется включить CAPTCHA/ограничения регистрации, чтобы снизить риск захвата чужих статиков.

Никаких SQL-миграций для этой замены формы не требуется. Не запускайте `schema.sql` из архива на существующей базе.
