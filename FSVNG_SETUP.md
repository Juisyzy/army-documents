# Установка ФСВНГ

1. Сначала выполните `FSVNG_MIGRATION.sql` в Supabase → SQL Editor.
2. Убедитесь, что SQL завершился без ошибок. Если есть ошибка, не публикуйте сайт — пришлите её текст.
3. Загрузите файлы сайта на Netlify (SQL и инструкции публиковать не обязательно).
4. Проверьте регистрацию нового тестового пользователя с подразделением ФСВНГ.
5. Проверьте отдельную кнопку ФСВНГ, черновик, публикацию и реестр.

Пока печать ФСВНГ временно совпадает с печатью ВС РО. Пользователь может загрузить собственную PNG-печать ФСВНГ, которая хранится в его браузере отдельно.

Важно: данная миграция исходит из структуры Supabase, применявшейся в прошлых обновлениях. Если схема базы менялась вручную, сначала проверьте SQL на тестовом проекте.
